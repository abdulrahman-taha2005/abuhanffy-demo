موقع أبو حنفي - نموذج تجريبي للعرض

التشغيل:
1) فك ضغط المجلد كاملًا.
2) افتح index.html باستخدام VS Code ثم Open with Live Server، أو افتحه مباشرة في المتصفح.

التحديثات:
- خط Cairo من Google Fonts مع fallback.
- معرض صور أكل ومشروبات ثلاثي الأبعاد يتحرك تلقائيًا ويمكن التحكم فيه.
- قسم تواصل وطلب يجهز رسالة ويفتح WhatsApp.
- تقييمات وتعليقات تجريبية محفوظة محليًا في المتصفح فقط.

قبل النشر الرسمي:
- تأكيد رقم واتساب المطعم وأرقام الاتصال.
- استبدال روابط الشبكات الاجتماعية بروابط أبو حنفي الرسمية.
- اعتماد المنيو والأسعار من الإدارة.
- التقييمات حاليًا محلية وليست نظام تقييمات عامًّا؛ النشر العام يحتاج قاعدة بيانات وخادمًا.
